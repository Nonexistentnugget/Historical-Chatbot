# Emperor Norton Chatbot

A full-stack interactive chatbot application that brings Emperor Norton back to life.

---

## Historical Context

**Joshua Abraham Norton (1818–1880)**, famously known as **Emperor Norton I**, was an eccentric and beloved resident of 19th-century San Francisco. After losing his fortune in a failed rice import venture in the 1850s, Norton declared himself *"Emperor of these United States"* in 1859 (and later *"Protector of Mexico"*).

Despite having no formal political power, he became a celebrated local figure in San Francisco:
* **Imperial Decrees:** He regularly issued proclamations in local newspapers, including abolishing the U.S. Congress and famously calling for a suspension bridge to be built connecting San Francisco and Oakland—a vision later realised with the Bay Bridge.
* **Norton Currency:** He printed his own currency, which was accepted as legal tender at many San Francisco restaurants and businesses.
* **Loyal Companions:** He was frequently seen inspecting the streets of San Francisco in a worn military uniform accompanied by two stray dogs, **Bummer and Lazarus**.

## Getting Started (Local Setup)

### Prerequisites
Make sure you have **Node.js** and **npm** installed on your machine.

### Installation & Running the App

1. **Clone the repository:**

2. **Install backend dependencies and start the Express server:**
   ```bash
   npm install
   node server.js
   ```
   The server should now be running at `http://localhost:5000`.

3. **Install frontend dependencies and start the development server:**
   Open a **new terminal**, navigate to the frontend folder, and run:
   ```bash
   cd frontend/client
   npm install
   npm run dev
   ```

4. **Open in your browser:**
   Click on or visit the local URL shown in your terminal (`http://localhost:5173`).
